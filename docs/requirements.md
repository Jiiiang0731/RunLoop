# RunLoop（环跑）需求分析（阶段 0 摘要）

## 核心需求
1. 输入目标跑步距离（5/10/15/20km 或自定义），默认容差 ±500m，内部尽量 ±300m。
2. 定位并在当前位置 500m–1km 内选起点（优先公园/绿道入口/易达道路）。
3. 生成 1–3 条候选闭合环线，展示真实距离、误差、起点、步行距离、配速时间、重复度、评分。
4. 路线预览 + 地图完整展示 + 导航步骤 + 一键跳转高德。
5. GPS 运动记录：开始/暂停/继续/结束、真实轨迹、距离、配速、后台/锁屏持续记录。
6. 跑步总结（距离/用时/配速/轨迹/时间/RPE/备注）并本地保存。
7. 历史记录与统计：今日/本周/本月/累计跑量、最长单次、配速趋势、LSD 次数。
8. 设置：距离容差、起点范围、路线偏好、定位权限、数据管理。

## 验收标准（首版关键）
- 15km → 生成 14.5–15.5km 闭合路线，起终点直线距离 <50m，起点在搜索半径内。
- 候选为真实规划结果，非静态示例；不同种子有合理变体。
- 真机：地图显示路线、定位、开始/暂停/继续/结束、轨迹保存、重启后历史仍在、周/月/累计统计正确、高德跳转、异常不崩溃。
- 交付：源码 + `dist/RunLoop-环跑-Android.apk` + README + 测试报告 + 已知限制。

## 非目标（首版不做，避免阻塞）
睡眠/静息心率、手表导入、GPX 导出、语音播报、收藏路线、夜间照明偏好等，均列入后续增强。
