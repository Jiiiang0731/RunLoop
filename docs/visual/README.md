# 阶段 M-F 视觉方案内部对比与定稿（任务书 6.1–6.4）

## 对比方法

本机无真机/模拟器，高德底图无法离线截屏。两套方案用 PIL 按 1:1 样式参数
（线宽比例、颜色、描边、箭头形态、去/返编码、五图层）在**模拟底图**
（道路 + 路名 + 楼块 + 阳光直射变体）上离屏渲染对比：

- `tools/visual_scheme_compare.py` → 渲染 `scheme_a.png`、`scheme_b.png`、
  `compare.png`（并排）、`sunlight.png`（阳光直射模拟）；
- `tools/visual_scheme_metrics.py` → 像素级客观指标（WCAG 相对亮度对比度、
  图层层间色差、重叠段双侧标注可见性）。

真机高德底图实拍截图列入待验证清单（见 `docs/phase_m_report.md`）。

## 两套方案

| | 方案 A · 导航对比风 | 方案 B · 轻量径迹风 |
|---|---|---|
| 主线 | 蓝→青渐变 6px（#2979FF→#00E5FF） | 深蓝细实线渐变（#1565C0→#1E88E5） |
| 描边 | 白色实体描边 | 同色半透明光晕 |
| 方向箭头 | 实心（去=深蓝 / 返=青绿，纯色区分） | 去=实心形 / 返=空心形（形状+颜色双编码） |
| 转弯标注 | 白圆底 + 彩色人字形 | 柔和半透明衬底 + 粗圆头人字形（无硬圆圈） |

## 结论（选择更清晰、更协调的一套）

**以方案 B 为主体定稿，吸收方案 A 的三处实测优势**：

1. **主线取 B 的深蓝细实线渐变**（#1565C0→#1E88E5）：A 的青色尾段对比度
   仅 1.38，阳光直射下会发淡；B 最低 3.31、最高 5.54，满足 6.4「强光可读」。
2. **描边取 A 的白色实体描边**：半透明光晕（B）在白色道路上几乎不可见，
   白描边是 K 阶段真机验证过的分离手段，且不影响路名/建筑名（6.1 线宽
   保持 2.8dp 细主线 + 4.6dp 描边）。
3. **GPS 轨迹取 A 的 #FF3D00、重规划段取 A 的琥珀 #FFB300**：层间色差
   118/338 显著优于 B 的 87/303——重规划段必须与 GPS 轨迹一眼可分（6.3）。
4. **去/返编码取 B 的形状双编码**：去程=深蓝实心箭头，返程=青绿空心箭头
   ——色觉障碍用户也能分辨（6.2「和谐区分」）。
5. **转弯标注取 B 的无圆圈轻量样式**：任务书 6.2 明确「不要使用圆圈包裹的
   > / < 符号」，改为柔和半透明白色衬底 + 粗圆头人字形，颜色语义保留
   （去=青 / 返=紫）。
